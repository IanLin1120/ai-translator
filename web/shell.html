Excel 翻譯

直接修改檔案內部資料，只換文字：格式、欄寬、公式、表格、圖表、圖片全部原樣保留。一次產生「僅翻譯版」與「中英夾雜版」（儲存格內一段原文、下方一段譯文）。

點一下選擇 Excel 檔（.xlsx / .xlsm）
支援多工作表
複雜的儲存格樣式（自訂色彩、條件式格式）在少數情況下可能無法完整保留，一般文字格式、欄寬與公式不受影響。

Word 翻譯

直接修改檔案內部資料，只換文字：段落樣式、字型、表格、清單、圖片、頁首頁尾全部原樣保留。一次產生「僅翻譯版」與「中英夾雜版」（每段原文下方接一段譯文）。

點一下選擇 Word 檔（.docx）
舊版 .doc 請先於 Word 另存為 .docx
圖片、頁首頁尾與複雜版面（分欄、文字方塊）目前不會複製到輸出檔案中，僅保留主要內文格式。

PDF 翻譯

保留每一頁的原始版面（文字位置與頁面外觀），將翻譯結果疊加在對應位置，輸出為可離線開啟的 HTML 檔案。

點一下選擇 PDF 檔
掃描檔（純圖片 PDF）辨識效果有限
PDF 沒辦法像 Word／Excel 那樣直接改內文，所以會依原文的段落順序與字級，重建成可編輯的 Word 檔（僅翻譯版／中英夾雜版，每頁分頁）；複雜版面（多欄、圖文混排）不保證與原檔一模一樣。需要貼著原頁面的版面時，可勾選上方選項另外產生「版面一致的 HTML 複本」，再用瀏覽器「列印 → 另存為 PDF」。掃描檔（純圖片）無法擷取文字。

Outlook 郵件翻譯

翻譯郵件主旨與內文，保留郵件標頭資訊（寄件者、收件者、時間）。

點一下選擇郵件檔（.eml）
.msg 請先在 Outlook 另存為 .eml
.msg 為 Outlook 專屬二進位格式，瀏覽器無法直接解析；本工具僅能嘗試擷取其中可讀文字，建議改用 .eml 以確保完整正確。

🪟 懸浮即時翻譯

在任何 App 上方浮出翻譯小視窗：框選要翻譯的區域，畫面一有變化就自動重新辨識與翻譯（看影片字幕、玩外文遊戲、讀外文網頁都能用）。

顯示在其他應用程式上層未允許
通知（前景服務需要）未允許
尚未啟動
使用方式：① 按「啟動」並在系統視窗按「立即開始」允許螢幕錄製　② 切到你要翻譯的 App，點懸浮的「譯」圓球　③ 在畫面上拖曳框選要翻譯的區域（框越小越準；影片字幕只框字幕那一條）　④ 翻譯小視窗會浮在上面，可拖曳移動、縮放字體、暫停。
小視窗不要蓋住所選區域；若不小心蓋住，程式會自動把被蓋住的部分塗掉，不會翻到自己的譯文。
懸浮即時翻譯需要安裝 APK 版 App（網頁沒有權限在其他 App 上方顯示）。

🎧 即時字幕（影片／通話／音檔）

聽到外文就即時翻成懸浮字幕，浮在影片、視訊或語音通話、音檔播放的畫面上方。字幕的顏色、大小、字體都能自訂。

語音模型：—

字幕樣式

Hello, how are you today?
你好，你今天好嗎？
字體尚未下載
手機的中文字不會因為系統字體家族而改變，所以另外提供真正的中文字體（開源授權）可下載，下載一次就能離線使用。
尚未啟動
使用方式：① 先選「聽到的語言」並下載語音模型（只要下載一次，之後離線辨識）　② 按「啟動」，允許錄音與螢幕錄製（要擷取手機播放的聲音才需要）　③ 切到影片／音檔 App 開始播放，字幕就會浮出來　④ 點字幕可顯示調整按鈕，拖曳可移動位置。
限制：• 視訊／語音通話（LINE、Zoom、Meet、電話等）的對方聲音，系統不允許擷取，請改選「麥克風」並開擴音　• 部分串流 App 禁止擷取聲音，會 15 秒沒收到聲音並提示　• 離線小模型的辨識準確度不如雲端，口音重、背景音樂大時會有錯字　• 擷取手機播放的聲音需要 Android 10 以上。
即時字幕需要安裝 APK 版 App。

🔑 翻譯引擎與金鑰

到 console.anthropic.com 申請。金鑰只存在這支手機，直接送到 Anthropic，不經過其他伺服器。不填也能用：Google 翻譯＋裝置端辨識完全免費。
免金鑰模式用的是 Google 沒有公開承諾的端點，偶爾會被限流。填入官方金鑰後改走正式 API（每月有免費額度，超過才計費；額度以官方價格頁為準）。
① 建立專案 ② 設定帳單 ③ 啟用 Translation API ④ 建立 API 金鑰 價格與免費額度
申請步驟（點開）
  1. 點「① 建立專案」，用 Google 帳號登入，取名後建立。
  2. 點「② 設定帳單」，綁定付款方式（Google 要求必須有帳單帳戶才能啟用，但在免費額度內不會扣款）。
  3. 點「③ 啟用 Translation API」，按「啟用」。
  4. 點「④ 建立 API 金鑰」→「建立憑證」→「API 金鑰」，複製以 AIza 開頭的字串貼到上面欄位。
  5. 建議點金鑰的「編輯」→「API 限制」→ 只勾選 Cloud Translation API，避免金鑰被盜用到其他服務。
  6. 貼上後按「儲存」，並在上方引擎選「Google 翻譯」即可。

☁ Claude 訂閱模式

用你的 Claude 月訂閱額度翻譯（不需要 API 金鑰、不另外計費）。App 會在內建瀏覽器開啟你發佈的網頁版翻譯器，請先登入 claude.ai。

在「翻譯」頁的翻譯引擎選「Claude 訂閱（月訂閱額度）」，翻譯會在背景透過這個網頁版進行、結果直接顯示在 App 介面裡。第一次請先登入 claude.ai，並按上面「開啟 Claude 訂閱版翻譯」翻譯一次、按「允許」。
登入請用 Email 驗證碼或連結（Google 登入在內建瀏覽器會被擋）。此模式為網頁版功能：文字、圖片、Excel、Word、PDF、郵件都能翻；螢幕懸浮即時翻譯只在本機模式提供。
